# Política de segurança

## Versões suportadas

O projeto ainda não tem release estável (todos os pacotes estão em `0.0.0`). Reporte
vulnerabilidades contra o branch de desenvolvimento ativo, `feat/arquitetura-v2`.

## Reportando uma vulnerabilidade

Não abra uma issue pública para falhas de segurança. Use a aba **Security → Report a
vulnerability** deste repositório no GitHub para abrir um advisory privado com o
mantenedor.

Se essa opção não estiver disponível (recurso "private vulnerability reporting" precisa
estar habilitado nas configurações do repositório), abra uma issue pedindo um canal de
contato privado, sem detalhar a vulnerabilidade nela.

Inclua, quando possível: passos para reproduzir, versão/commit afetado, e o impacto
esperado (ex.: qual invariante de `docs/backend-v2.md` a falha quebra).
